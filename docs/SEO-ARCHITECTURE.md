# SEO architecture

## Canonical host

`https://www.blossompot.com` — apex 301s in middleware. All canonicals use `NEXT_PUBLIC_SITE_URL`.

## Sitemaps

| URL | Contents |
|-----|----------|
| `/sitemap.xml` | Static pages, categories, products, blog, USA **state** hubs, international locations |
| `/sitemap-geo.xml` | Published USA geo pages (`/gifts-to-*`) |
| `/sitemap-locations.xml` | `/locations` hub + indexable international pages only |

Unpublished, draft, thin, or noindex locations are omitted.

## robots.txt

Generated by `apps/web/src/app/robots.ts`. Allows public content for `*` and named search/AI crawlers. Disallows admin, vendor, cart, checkout, account, private APIs.

## Structured data

- Sitewide: Organization, WebSite, OnlineStore (`apps/web/src/lib/seo.ts`)
- USA geo: Service + FAQ + BreadcrumbList (`GeoLocationTemplates`)
- International: WebPage + Service (USA delivery) + FAQ + BreadcrumbList — **no fake LocalBusiness**
- Products: Product + Offer when the SKU is real

## hreflang

Homepage: `x-default`, `en`, `en-US` only. We do **not** tag Toronto vs Sydney as language alternates. Add reciprocal hreflang only when two URLs are true locale variants of the same content.

## Duplicate-content controls

- USA hierarchy under `/locations/united-states/...` 301s to `/gifts-to-*`
- International pages are origin guides with unique intros (quality gate)
- Search result URLs on `/products?search=` stay noindex

## LLM / AI search

- `/llms.txt` and `/llms-full.txt` summarize the business and link locations
- Important facts are in HTML (not widgets-only)
- Crawler policy: `docs/CRAWLER-POLICY.md`
